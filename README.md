# The Sterling Room — MKTG:4400

Fictional five-page upscale, affordable brewpub website created for a University of Iowa class project. No real business, reservations, orders, or physical location.

## Publishing
1. Create a public GitHub repository named `sterling-room`.
2. Upload all files in this folder to the repository root.
3. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml` with your GitHub username (and adjust `sterling-room` if your repository has a different name).
4. Settings → Pages → Deploy from branch → main → / (root) → Save.
5. Check the live website and the two SEO files.
6. Verify the URL-prefix property in Google Search Console, submit `sitemap.xml`, and capture actual baseline screenshots and measurements.

## Notes
- All site content and prices are fictional.
- The Lookbook uses CSS illustrations; no third-party photography is required.
- Keyword volumes, competition metrics, Search Console baselines, and commits on different days must be obtained or completed separately.
